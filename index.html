Einstellungen

Marge-Basis

Vom Verkaufspreis: Marge = Verkaufspreis × Zielmarge. Auf GIK: die Marge wird auf die Gesamtinvestition aufgeschlagen.

Kaufnebenkosten

In % werden die Kaufnebenkosten als Anteil vom Einkaufspreis gerechnet.

Setzt Objektwerte und Parameter beider Seiten auf die Standardwerte zurück; die Einstellungen bleiben.

Alle Eingaben zurücksetzen?

Objektwerte und Parameter beider Seiten werden auf die Standardwerte gesetzt.
